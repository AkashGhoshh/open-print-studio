## 2. Workspace Rules & Enforcement

In addition to the 12 on-demand skills above, workspace-wide rules are enforced by [`AGENTS.md`](../AGENTS.md) and [`.agents/rules/open-print-studio.md`](../.agents/rules/open-print-studio.md):
1. **100% Offline-First**: Zero telemetry, no remote analytics, offline models/fonts.
2. **Synthetic Data Only**: Real identity cards are strictly prohibited.
3. **Computation Over Assertion**: All capacities and dimensions must be mathematically derived.
4. **Clean-Room Neutrality**: All keys and events use `ops_`.
5. **Architectural Deviation Tracking**: All corrections must be logged in [`docs/DECISIONS.md`](./DECISIONS.md).
6. **Pure Core Package**: Mathematical geometry logic must reside in `@ops/core` without UI dependencies.
